Динамикалық деректер құрылымдарын программалау

Мәліметтердің типтік динамикалық құрылымын программалау

Жұмыс мақсаты: Файлдан және клавиатурадан форматталған берілгендерді енгізу және нәтижені экранға және файлға шығаруды оқып- үйрену.

Жұмыстың орындалу тәртібі:

С++ тілінің файлдарымен жұмыс істейтін операторларымен танысу

Берілген жұмысқа әдістемелік нұсқаумен танысу

Келтірілген мысалдарды талдау

Жеке тапсырмадағы есептерді шешудің алгоритмдері мен программасын түзу

Программаны ЭЕМ - де орындау

Бақылау сұрақтарына жауап беру

ӘДІСТЕМЕЛІК НҰСҚАУ

С++ тіліндегі енгізу-шығару операциялар кітапханалық функциялар көмегімен ұйымдастырылады. С++-дің стандарттық кітапханасында енгізу/шығару функциялары файлдардан берілгендерді оқуды немесе оларды енгізу құрылғысынан алуды және файлдарға берілгендерді жазуды немесе оларды әртүрлі құрылғыларға енгізуге мүмкіндік береді.

Енгізу/шығару функциялары үш класқа бөлінеді:

Жоғарғы деңгейдегі енгізу/шығару (“ағын” түсінігін пайдалану арқылы).

Консольдық терминал үшін енгізу/шығару

Төменгі деңгейдегі енгзу/шығару(“дескриптор” түсінігін пайдалану арқылы).

Мысалы 1. А дискісіндегі phone.txt файлын досыңыздың фамилиясын, телефон номерімен толықтыруыңыз керек. Егер дискіде файл жоқ болса, онда программа оны құру керек. Файлда деректер элементы (аты, фамилиясы, телефоны) жеке қатарда орналасуы қажет.

// Фамилияны, атын, телефон номерін файлға толықтырады. #include "stdio.h"
#include "conio.h"

#define FNAME "a:phone.txt\0" // файл аты

void main()

{

char fname[20] = FNAME;

FILE *out; // сандар файлы

char fam[15]; // фамилиясы

char name[15]; // аты

char tel[9]; // телефон номері

puts("\n Телефон анықтамасын толықтыру");

// (t) мәтінін қосу режимінде (а) файл мәтінін ашу

// Егер бұл атпен файл жоқ болса, онда ол құрылады

if ((out = fopen(fname, "at")) == NULL)

{

printf("Толықтыру үшін файлды ашу қателігі");

getch();

return;

}

// пайдаланушыдан мәліметтерді аламыз

printf("Фамилиясы ->");

scanf("%s", &fam) ;

printf("Аты ->");

scanf("%s", &name);

printf("Телефоны ->");

scanf("%s", &tel);

//оларды файлға жазамыз

fprintf(out,"%s %s %s", fam, name, tel);

puts("Ақпарат қосылды");

fclose(out); // файлды жабу

printf("\n\n Аяқтау үшін <Enter> - ді басыңыз\n");

getch();

}

Тапсырма варианттары:

Компоненттері нақты сандар болып табылатын f файл берілген. Табу керек: а) f файлының компоненттерінің қосындысын; б) файлдың соңғы компонентін.

Компоненттері нақты сандар болып табылатын f файл берілген. Табу керек: а) жұп нөмерлі компоненттердің ең кішісін анықтау; б) файл компонентінің бірінші және соңғы айырымын анықтау.

Компоненттері нақты сандар болып табылатын f1, f2, f3 , f4, f5 файлдары берілген. Файлдардың арасында келесі түрде компоненттер алмасуын ұйымдастыру: f1 файлының компоненты f3 файлына жазылады, f2 файлы - f4-ке, f3 - f5, f4 - f1, f5 - f2. h көмекші файлын пайдалануға болады.

Компоненттері бүтін мәнді f файлы берілген. F файлының жұп сандарын g файлына, ал тақ сандарын h файлына жазу керек.

f С++мвольды файл берілген. G файлына f файлының мәндерін кері ретпен жазу керек.

Компоненттері нақты мәнді f файлы берілген. Табу керек: файлдың соңғы және бастапқы компонентінің осындысын.

Компоненттері бүтін мәнді f файлы берілген. Табу керек: компоненттердің ең үлкенін анықтау.

Компоненттері нақты мәнді х файлы берілген. Табу керек: компоненттердің көбейтіндісін.

Компоненттері нақты мәнді f файлы берілген. F файлдың тақ сандарын g файлына, ал жұп компоненттеріни h файлына.

Компоненттері оң таңбалы f файлы берілген. Табу керек: а) жұп номерлі компоненттердің геометриялық ортасын; б) бірінші және соңғы файл компонентінің қосындысын

11. Жақсы көретін 4 шумақ өлең жолдары бар текстік файл құру. Құрылған файлды қарап шығу. 2-ші куплетпен файлды толықтыру.

12. Текстік файл құру. Онда қатарлар санын есептеу.

13. Фам.dat файлында білімгерлер туралы мәлімет бар: фамилиясы, орта балл. Жаңа файл құру керек және онда тек Фам.dat файлындағы білімгерлердің фамилиясы қажет.

14. РЕОР.dat файлында адамдар туралы мәлімет бар: фамилиясы, жасы, жынысы. Қыздарды және ұлдардың фамилиясы екі әр түрлі текстік файлда болу керек.

15. Текстік файл құру керек. Қатар бойынша оның номерін алдына қойып баспаға беру.
