Құрылымдарды анықтау және қолдану

Құрылымдарды анықтау және қолдану.

Жұмыс мақсаты: Құрылымдар туралы теориялық мәліметтерді игеріп, программа құруға машықтану

Студенттерге қойылатын талап: Кез келген студент берілген тапсырмаларға программалар жазып, ЭЕМ-де есептеп, нәтижесін алуы тиіс.

Жұмыстың орындалу тәртібі:

С++ тілінің құрылыммен жұмыс істейтін операторларымен танысу

Берілген жұмысқа әдістемелік нұсқаумен танысу

Келтірілген мысалдарды талдау

Жеке тапсырмадағы есептерді шешудің алгоритмдері мен программасын түзу

Программаны ЭЕМ - де орындау

Бақылау сұрақтарына жауап беру

ӘДІСТЕМЕЛІК НҰСҚАУ

Құрылым әртүрлі типті, бірнеше айнымалыларды біріктіреді. құрылыммен біріктірілген айнымалылар мүшелер, элементтер немесе құрылымның өрісі деп аталады.

Мысалы:

struct student

{ char name [30];

int kurs;

char group[3];

int stip;};

struct student типтің нақты айнымалыларын жариялау үшін, struct student stud1, stud2 -деп жазсақ болады.

құрылымның нақты элементіне ену “нүкте”(dot) операциясының көмегімен іске асырылады.

Мысалы:

strepy (stud1.name, “С++доров П.Р.”);

немесе

printf (“%s”,stud2.group);

құрылымдар, басқа типті айнымалылар тәрізді құрылымды массивке біріктірілуі мүмкін. құрылымды массивті жариялау үшін, алдымен құрылымның шаблонын беру керек (бізде student шаблоны бар), ал содан кейін массивті хабарлау орындалады:

struct student study [200];

Массивтің 25-ші элементіне kurs өрісіне ену үшін:

study [24].kurs

Әрбір жеке типтерге ену

С++ тілі байттағы немесе сөздегі бір немесе бірнеше биттерге енуді қамтамасыз етді. Олардың өзінің артықшылығы бар. Бір тәсілі- бұл биттер өрісі (bit fields). Биттер өрісі -құрылымның мүшелерінің арнайы

типтері. Мұнда әрбір элемент қанша биттен тұратындығын анықтайды. Осындай құрылымның негізгі түрі төменде көрсетілген:

struct құрылым_аты

{типі аты1: бит_ұзындығы;

типі аты2: бит_ұзындығы;

....

типі атыN: бит_ұзындығы;};

құрылымда типтер :int, unsigned немесе signed болуы мүмкін.

құрылым ұзындығы әрдайым сегізге кратна. Егер, былай деп көрсетсек,

struct onebit

{ unsigned one_bit: 1;

} obj;

онда obj айнымалысы үшін 8 бит бөлінеді, бірақ бірінші ғана пайдаланады.

Біріктіру

С++ тілінде әртүрлі типті бірнеше айнымалыларды жадыда орналастыру үшін тағы бір тип анықталды. Бұл біріктіру. Біріктіру, құрылым С++яқты хабарланады, мысалы:

union u

{ int i;

char ch;

long int 1; };

Бұл біріктіру қандай да бір айнымалыны бермейді. Ол біріктіру шаблонын береді. Айнымалыны былай хабарлауға болады:

union u alpha, beta;

Жоғарыда көрсетілген мысалда, alpha айнымалыға жадыда 4 байт орын бөлінеді. Ал негізінен і элемент 2 байт, сh элемент - 1 байт және 1 элемент -4 байт қажет етеді. қалған айнымалылар жадының сол жерінде орналасады. Біріктіру элементтерін пайдалану С++нтакС++сі құрылымдағыдай:

u.ch=’5’;

Саналатын тип

Саналатын тип (enumeration) -бүтін тұрақтылардың аттарымен берілген жиын. Саналатын тип, осы типтің барлық айнымалыларының жіберілетін барлық мәндерін анықтайды. Типтің хабарлануы келесі түрде болады:

enum типтің_аты { аттар_тізімі }айнымалылар тізімі;

Айнымалылар тізімі бос болуы мүмкін.

Мысалы:

enum seasons {win, spr, sum, aut};

enum seasons s;

Бұл типтің негізгі түсініктемесінің кілті болып, win, spr, sum, aut әрбір аттары бүтін шаманы көрсетеді. Егер бұл шамалар басқаша анықталмаса, онда үнсіздік бойынша олар сәйкес нөл, бір, екі және үшке тең болады.

prinf (“%d%d”,win, aut);

операторы экранға 0 және 3 сандарын береді. Типті хабарлау уақтысында бір немесе бірнеше С++мволдарға басқа мәндерді меншіктеуге болады. мысалы:

enum value {one=1, two, three, ten=10, thousand=1000, next};

Енді мәндерді баспаға шығарғанда,

printf (“%d%d%d%d%d\n”,one,two,ten,thousand, next};

онда экранда 1 2 10 1000 1001 сандары экранда шығады, яғни әрбір келесі С++мвол алдыңғымен салыстырғанда,бірге өседі.

Саналатын типті айнымалылармен келесі операцияларды жүргізуге болады:

enum типті айнымалыға, сол типті басқа айнымалыны меншіктеу;

тең немесе теңсіздікті тексеру мақсатымен салыстыруды жүргізу;

enum типті (і=win-aut) тұрақтылармен арифметикалық операциялар.

enum типті айнымалыларға арифметикалық операциялар және ++ операциясын және - - операциясын пайдалануға болмайды.

Typedef -типтердің атын өзгерту

С++ тілінде бар берілгендер типтеріне жаңа ат беруге мүмкіндігі бар. Ол үшін тypedef қызметші сөзі қолданады. Бұл жағдайда жаңа берілгендер типі құрылмайды.

Мысалы:

typedef char SYMBOL;

typedef unsigned UNSIGN;

typedef float real;

құрылымды қолдану арқылы typedef операторын пайдалану жиі кездеседі:

typedef struct st_tag

{ char name[30];

int kurs;

char group [3];

int stip;

} STUDENT;

Айнымалыны анықтау үшін, struct st_tag avar; пайдалануға болады және де STUDENT avar пайдалануға да болады.

Бір варианттың орындалуы

№1 тапсырма. Құрылымды - функция параметрі ретінде пайдалану.

Шешімі:

#include <stdio.h>

struct stru

{int x;

char e;

};

void f(struct stru param); /*прототип*/

main (void)

{ struct stru arg;

arg.x=1;

arg.e=’2’;

f(arg);

return 0; }

void f(struct stru param)

{ printf(“Программа нәтижесі:%d%c\n”,param.x,param.y); }
