Динамикалық типті анықтау және типтерді түрлендіру

Динамикалық типті анықтау және типтерді түрлендіру

Жұмыстың мақсаты: typeid, dynamic_cast, static_cast, const_cast, reinterpret_cast құралдарының қызметін түсіну және оларды орынды қолдану.

Студенттерге қойылатын талап: полиморфты кластар иерархиясын құру, объектілердің нақты типтерін анықтау және сәтті әрі сәтсіз түрлендірулерді тексеру.

Әдістемелік нұсқаулар

RTTI — программа орындалу кезіндегі тип туралы ақпарат механизмі. Полиморфты класта кемінде бір виртуалды әдіс болады.

Нұсқауышпен орындалатын тексерілетін dynamic_cast сәтсіз болса, нәтиже nullptr болады. Сілтемемен орындалатын осындай түрлендіру сәтсіз болса, std::bad_cast тудырылады.

const_cast арқылы бастапқыда const болып құрылған объектіні өзгертуге болмайды: бұл анықталмаған әрекетке әкеледі.

Жұмыстың орындалу тәртібі

Shape базалық класын құру.

Одан Circle және Rectangle кластарын туындату.

Объектілерді базалық нұсқауыш арқылы қарастыру.

typeid арқылы нақты типтерін тексеру.

Сәтті және сәтсіз dynamic_cast орындау.

Қалған түрлендіру операторларының мысалдарын талдау.

Жеке тапсырманы орындап, есеп дайындау.

Программалық мысал

#include <iostream>
#include <memory>
#include <vector>
#include <typeinfo>
class Shape {

public:

virtual ~Shape() = default;

virtual double area() const = 0;

};

class Circle : public Shape {

private:

double radius_;

public:

explicit Circle(double radius) : radius_(radius) {}

double area() const override {

return 3.141592653589793 * radius_ * radius_;

}

double radius() const {

return radius_;

}

};

class Rectangle : public Shape {

private:

double width_;

double height_;

public:

Rectangle(double width, double height)

: width_(width), height_(height) {}

double area() const override {

return width_ * height_;

}

double width() const {

return width_;

}

};

int main() {
std::vector<std::unique_ptr<Shape>> shapes;

shapes.push_back(std::make_unique<Circle>(3.0));

shapes.push_back(std::make_unique<Rectangle>(4.0, 5.0));

for (const auto& owner : shapes) {

Shape* shape = owner.get();

// typeid арқылы нақты типті салыстыру

if (typeid(*shape) == typeid(Circle)) {

std::cout << "Tip: Circle\n";

}

else if (typeid(*shape) == typeid(Rectangle)) {

std::cout << "Tip: Rectangle\n";

}

std::cout << "Audan: " << shape->area() << '\n';

// Тексерілетін төмен қарай түрлендіру

if (auto* circle = dynamic_cast<Circle*>(shape)) {

std::cout << "Radius: " << circle->radius() << '\n';

}

else {

std::cout << "Circle* turine turlendiru satsiz.\n";

}

if (auto* rectangle = dynamic_cast<Rectangle*>(shape)) {

std::cout << "Eni: " << rectangle->width() << '\n';

}

std::cout << '\n';

}

// Сандық түрлендіру

double number = 12.75;

int integer = static_cast<int>(number);

std::cout << "static_cast natizhesi: " << integer << '\n';

// Бастапқы объект const емес, сондықтан оны өзгертуге болады

int value = 10;

const int* readOnly = &value;

int* writable = const_cast<int*>(readOnly);

*writable = 25;

std::cout << "const_cast mysaly: " << value << '\n';

// Объектінің байттық көрінісін unsigned char арқылы оқу

const unsigned char* bytes =

reinterpret_cast<const unsigned char*>(&value);

std::cout << "Obekt baittary: ";

for (std::size_t i = 0; i < sizeof(value); ++i) {

std::cout << static_cast<unsigned int>(bytes[i]) << ' ';

}

std::cout << '\n';

return 0;

}

Түсіндірме: std::unique_ptr объектілердің жадын автоматты босатады. Соңғы мысалда объект байттары тек оқылады; олардың реті мен мәндері платформаның деректерді ұсыну тәсіліне тәуелді.

Күтілетін нәтижелер

Жеке тапсырманың нұсқалары

Әр нұсқада виртуалды деструктор, кемінде бір виртуалды әдіс, typeid салыстыруы және сәтті әрі сәтсіз dynamic_cast болуы керек.

Қосымша тапсырмалар:

dynamic_cast сілтеме нұсқасының сәтсіздігін std::bad_cast арқылы өңдеңіз.

Бір сандық static_cast мысалын қосыңыз.

typeid(*pointer).name() нәтижесін шығарып, оның жазылуы компиляторға тәуелді екенін түсіндіріңіз.

Бақылау сұрақтары

RTTI қандай мақсатта қолданылады?

Полиморфты класс дегеніміз не?

typeid полиморфты объектінің қандай типін анықтайды?

dynamic_cast нұсқауыш үшін сәтсіз болса, не қайтарылады?

Сілтеме үшін сәтсіз dynamic_cast қалай өңделеді?

static_cast пен dynamic_cast айырмашылығы қандай?

const_cast қолданғанда қандай шектеуді сақтау қажет?

reinterpret_cast неге мұқият қолданылуы керек?
