Ерекше жағдайларды өңдеу

Ерекше жағдайларды өңдеу

Жұмыстың мақсаты: C++ тіліндегі try, throw, catch механизмдерін меңгеру және қате жағдайларды өңдейтін программа құру.

Студенттерге қойылатын талап: берілген мысалды орындау, жеке тапсырма бойынша программа құру және қалыпты әрі қате деректермен алынған нәтижелерді түсіндіру.

Әдістемелік нұсқаулар

Ерекше жағдай — программаның қалыпты орындалуын бұзатын жағдай туралы хабарлау механизмі. Мысалы, файлдың ашылмауы, рұқсат етілмейтін аргумент немесе контейнер шегінен шығу.

Ерекше жағдайларды өңдеуде:

try — ерекше жағдай туындауы мүмкін кодты қамтиды;

throw — ерекше жағдайды тудырады;

catch — сәйкес ерекше жағдайды ұстап, өңдейді.

Нөлге бөлуді ерекше жағдай арқылы өңдеу үшін бөлгішті алдын ала тексеріп, throw қолдану қажет. Арифметикалық нөлге бөлу өздігінен стандартты C++ ерекше жағдайын тудырмайды.

Стандартты ерекше жағдайларға std::invalid_argument, std::out_of_range, std::runtime_error жатады. Ерекше жағдайларды тұрақты сілтеме арқылы ұстау ұсынылады:

catch (const std::exception& e) {

std::cout << e.what();

}

Жұмыстың орындалу тәртібі

Ерекше жағдайларды өңдеу механизмін қайталау.

Төмендегі программаны теріп, іске қосу.

Оны қалыпты деректермен тексеру.

Нөлдік бөлгіш, қате индекс және санның орнына мәтін енгізу жағдайларын тексеру.

Жеке тапсырманы орындау.

Нәтижелерді есепке енгізіп, бақылау сұрақтарына жауап беру.

Программалық мысал

Есеп: екі санның бөліндісін есептеу және вектор элементін индексі бойынша шығару. Қате жағдайларды өңдеу.

#include <iostream>
#include <vector>
#include <stdexcept>

double divide(double a, double b) {

if (b == 0.0) {

throw std::invalid_argument("Bolgis nol bolmauy kerek.");

}

return a / b;

}

int main() {

// Бірінші әрекет: бөлу

try {

double a, b;

std::cout << "Eki san engiziniz: ";

if (!(std::cin >> a >> b)) {

throw std::runtime_error("Sandardy engizu qatesi.");

}

double result = divide(a, b);

std::cout << "Bolindi: " << result << '\n';

}

catch (const std::invalid_argument& e) {

std::cout << "Argument qatesi: " << e.what() << '\n';

}

catch (const std::runtime_error& e) {

std::cout << "Engizu qatesi: " << e.what() << '\n';

return 1;

}

// Екінші әрекет: элементке индекс бойынша қатынау

try {

std::vector<int> values{10, 20, 30, 40, 50};

int index;

std::cout << "Indeks engiziniz (0-4): ";

if (!(std::cin >> index)) {

throw std::runtime_error("Indeks engizu qatesi.");

}

if (index < 0) {

throw std::out_of_range("Indeks teris bolmauy kerek.");

}

int value = values.at(static_cast<std::size_t>(index));

std::cout << "Element: " << value << '\n';

}

catch (const std::out_of_range& e) {

std::cout << "Indeks qatesi: " << e.what() << '\n';

}

catch (const std::exception& e) {

std::cout << "Qate: " << e.what() << '\n';

}

return 0;

}

Түсіндірме: vector::at() индекс шектен шыққанда std::out_of_range ерекше жағдайын тудырады. operator[] мұндай тексеруді қамтамасыз етпейді.
