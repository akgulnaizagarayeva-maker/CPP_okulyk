Шартты операторларды қолдану

Бұл бөлімде бастапқы құжаттағы №2 және №3 зертханалық жұмыстар бірге берілген.

С++ тілінде шартты операторды қолданып программа құру.

Жұмыс мақсаты: Студенттерді практика жүзінде басқару конструкцияларын және басқа да операторларын пайдаланып, С++ тілінде программалар жазуға үйрету.

Студенттерге қойылатын талап: Кез келген студент берілген тапсырмаларға программалар жазып, ЭЕМ-де есептеп, нәтижесін алуы тиіс.

Жұмыстың орындалу тәртібі:

Берілген жұмыстың әдістемелік нұсқауымен танысу.

Берілген бақылау сұрақтарына жауап беру.

Жаттығуларды талдау.

Компьютерден нәтижені алу.

ӘДІСТЕМЕЛІК НҰСҚАУЛАР

Программа дегеніміз - есепті шешу алгоритмін программалау тілдерінің жабдықтарын пайдаланып С++паттау. Кез келген алгоритм тізбектелген, тармақталған және қайталау процестерінен тұрады. Бірінен соң бірі орындалатын амалдар тізбегі - тізбектелген болып табылады. Егер көптеген есептерді шешкенде қойылған шарттың орындалуы немесе орындалмауына байланысты шешу жолдарын таңдау- тармақталу, ал амалдар тізбегін қайталап орындайтын болсақ, кайталау процесін пайдаланамыз.

IF операторы

Бұл команданы (операторды) екі түрде пайдалану мүмкін:

а) if (өрнек)

1-ші оператор;

else

2-ші оператор;

б) if (өрнек)

1-ші оператор;

Егер өрнек (кейбір шарттар) нольге тең болмаса, онда 1-ші оператор орындалады. Оператор жай немесе құрама болуы мүмкін. құрама оператор - фигуралық жақшаның {} ішіне кіретін операторлар (командалар) жиынтығы. Жақшаның ішіндегі әрбір оператор нүктелі үтірмен аяқталады.

Мысалы:

#include<stdio.h>

main()

{ float a, b, res;

printf(Екі санды енгіз:);

scanf(%f%f ,&a, &b);

if (b= =0)

printf(a/b қатынасы анықталмаған\n );

else

{ res = a/b;

printf (a/b тең%f\n , res);}}

SWITCH таңдау операторы

С++ тілінде көп жақты таңдау жасайтын орнатылған оператор бар. Оның негізгі формасы мына түрде болады:

switch (өрнек)

{ case constant1:

операторлардың тізбегі

break;

case constant2:

операторлардың тізбегі

break;

...

case constantN:

операторлардың тізбегі

break;

default

операторлардың тізбегі

}

Алдымен switch негізгі сөзінен кейін, жақшаның ішіндегі тұрған өрнектер есептелінеді. Содан кейін есептелінетін өрнектің мәніне сәйкес метка табылмағанша, белгілер тізімі (case constant және т.б.) қарастырылады. қос нүктеден кейінгі операторлардың тізбегі жалғастырылып орындалады. Егер де өрнектің мәні switch операторының ешбір белгісіне сәйкес келмесе, онда default негізгі сөзінен кейінгі операторлар тізбегі орындалады.

#include<stdio.h>

main()

{ char ch;

printf(Қазақ алфавитінің бас әріптерін енгіз:);

сh = getchar ();

if (ch>=’A’&&’ß’)

switch (ch)

{ case ‘A’:

printf(Ахметов\n );

case ‘Б’:

printf(Бокеев\n );

case ‘В’:

printf(Валашов\n );

case ‘Г’:

printf(Газизов\n );

default:

printf (Дастанов, Зейінқұлов және басқалар\n );

}

else printf (Қазақ алфавитінің бас әріптерін енгізуіңіз керек еді\n);

Циклдің әртүрлі операторлары бар программалармен жұмыс орындау. }

Бір варианттың орындалуы

№1 тапсырма. a және b екі нақты сандары берілген. Max (a,b) алуымыз керек.

Шешімі:

#include<stdio.h>

main()

{ float a, b, max;

printf (Екі санды енгізіңіз:);

scanf (%e%e ,&a,&b);

if (a>b) max =a; else max=b;

printf(Екі санның ең үлкені= %e\n,max);

}

Нәтижесі:

Екі санды енгізіңіз: 45 89

Екі санның ең үлкені= 89

№2 тапсырма. х, у және z нақты сандары берілген. max (x+y+z, xyz) есептеу керек.

Шешімі:

#include<stdio.h>

main()

{ float x, y, z, a, b, max;

printf (°ш санды енгізіңіз:);

scanf (%f%f%f ,&x,&y,&z);

a=x+y+z; b=x*y*z;

if (a>b) max =a; else max=b;

printf(Екі санның ең үлкені= %f\n,max);

}

Нәтижесі:

Үш санды енгізіңіз: 3 4 5

Екі санның ең үлкені= 60

№3 тапсырма. x және y екі нақты сандары берілген. X,Y координаттарымен берілген нүкте, жазықтықтың штрихталған бөлігіне кіретіндігін анықтау.

еlse printf (Нүкте кесіндіге жатпайды);
