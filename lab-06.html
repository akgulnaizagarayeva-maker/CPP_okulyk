Пайдаланушы функцияларын құру

Пайдаланушының қарапайым функцияларын құру.

Жұмыс мақсаты: Жаңа типтердi өңдеу және оларды программаларда пайдаланудағы ерекшелiктер

Студенттерге қойылатын талап: Кез келген студент берілген тапсырмаларға программалар жазып, ЭЕМ-де есептеп, нәтижесін алуы тиіс.

Жұмыстың орындалу тәртібі:

С++ тілінің пайдаланушының қарапайым функцияларны құру функцияларымен танысу

Берілген жұмысқа әдістемелік нұсқаумен танысу

Пайдаланушы анықтайтын берiлгендер типi екi әдiспен пайдалануға берiледi. Бiрiншi тәсiл - жаңа берілгендер типiн енгiзу. Екiншi тәсiл - әртүрлi модификаторлы типтердi (type modifiers) қолдану. Модификаторлы типтер негiзгi базалық типтерге қолдануы мүмкiн. Мұндай модификаторлар 4 типтi:

ену (доступ) модификаторы (const және voliatile)

жадының модификаторлы класы (auto, static, extern және register).

функцияның Borland C++ модификаторлы типi.

жадының Borland C++ модификаторлы моделдерi

Типтiң модификаторын пайдалану келесi түрде орындалады:

модификатор_типi типтiң_спецификаторы <айнымалылар _тiзiмi>

яғни, модификатор типтiң атының алдыңда қойылады.

Const модификаторы С++ тiлiнде С++ ++ тiлi шыққаннан соң шықты. Const модификаторымен хабарланған айнымалылар, программаның жұмыс iстеу барысында өзгертiлмейдi. Const модификаторы көмегiмен типтес, аттас тұрақтылар құралады.

Хабарлау мысалдары:

const float radius = 15.5;

const char yes = ‘y’;

сonst типiнiң ең қажеттi колданылуы - функция аргументтерiн өзгертулерден сақтайды. Егер функцияның аргументi болып, айнымалыға көрсеткiш табылатын болса, онда бұл айнымалының мәнi функцияны шақыру кезiнде өзгертiлуi мүмкiн. Егер де бұл айнымалыны const ретiнде С++паттасақ, онда функция бұл айнымалының мәнiн өзгерте алмайды.

Жолдың кодталу мысалы:

# include <stdoi.h>

void code (const char *str);

main (void)

{ code (“Это тест”);

return 0; }

void code (const char *str)

{ while (*str) printf (“%c”,(*str++)+1);}

Бұл айнымалыны өзгерткен кезде, мысалы, операциондық жүйенің жүйелік функциясын,voliatile модификаторы пайдаланамыз. Мысалы, компьютердің жүйелік уақыты бар глобальдық айнымалы.

Const және volatile модификаторлары бір уақытта пайдалану мүмкін:

Const volatile unsigned char*port=0x30;

Бұл хабарлама қажет болады, егер процессор портының 0x30 мәні тыс(извне) өзгертілген деп жорамалдасақ.

Borland C++ тән келесі спецификалық модификатордың түрі - функция типінің модификаторы. Бұл модификаторлар MS DOS операциондық жүйесінің программалау жүйесінде қажетті болады. Олар үшеу: pascal, cdecl және interrupt.

pascal, cdecl модификаторлары компиляторға, функция параметрлерін беру, С++ және Паскаль тілдеріне сәйкес ұйымдастырылады. Оған қажеттілік С++ тілінде жазылған программаларды, Паскаль тіліндегі программалармен бірге пайдалану кезінде туады.

Pascal factorial (register int n);

{ register int i=1;

for (;n;n--) i*=n;

return i;}

Егер де сіз, біреуінен басқа барлық функцияларды, Паскаль тіліндегідей параметрлерді беруді компиляциялау С++яқты, онда интегралдық ортада сәйкес опцияны орнатады. Функция үшін, параметрлерді С++ тіліндегідей беру үшін, осы функцияның типінің алдыңда cdecl модификаторын орнату керек.

interrupt модификаторы, компиляторға функция осы модификатормен үзілісті өңдеуді іске асыратындығын хабарлайды. Бұл модификатор резиденттік программаларды құруда пайдаланады.

Бізге танымал С++ тіліндегі берілгендер типінен басқа, 5 берілгендер типін құруға мүмкіндігі бар:

құрылымдар (structure),

біріктіру (union),

cаналатын тип (enumeration),

өрістер биті (bit fields),

5-ші мүмкіндігі - typdef операторының көмегімен бар тип үшін жаңа ат құру.
