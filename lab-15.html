Стандартты кітапхана және жалпыланған программалау

Стандартты кітапхана және жалпыланған программалау

Жұмыстың мақсаты: функция үлгілерін, STL контейнерлерін, итераторларды, алгоритмдерді және функционалдық объектілерді қолдану дағдыларын қалыптастыру.

Студенттерге қойылатын талап: деректерді контейнерде сақтау, стандартты алгоритмдермен өңдеу және әртүрлі типке қолданылатын үлгілік функция құру.

Әдістемелік нұсқаулар

STL құралдары контейнерлерден, итераторлардан және алгоритмдерден тұрады.

Алгоритмдер жиі [begin, end) диапазонымен жұмыс істейді: бастапқы элемент кіреді, ал соңғы итератор көрсететін позиция кірмейді. end() итераторын дерек алу үшін қолдануға болмайды.

Функционалдық объект — operator() анықталған кластың объектісі. bool қайтаратын шарттық функция немесе функционалдық объект предикат ретінде қолданылады.

Жұмыстың орындалу тәртібі

Үлгілер мен STL құралдарын қайталау.

Берілген программаны іске қосу.

Сұрыптау, іздеу, санау және жиынтық есептеу нәтижелерін тексеру.

Итератор арқылы элементтерді экранға шығару.

Үлгілік функцияны int және double типтерімен қолдану.

Жеке тапсырманы орындау.

Есеп дайындау.

Программалық мысал

Есеп: бүтін сандарды сұрыптау, олардың қосындысын және оң элементтер санын есептеу, берілген мәнді іздеу және қайталанбайтын элементтерді шығару.

#include <iostream>
#include <vector>
#include <set>
#include <map>
#include <algorithm>
#include <numeric>
#include <string>
template<typename T>
void printContainer(const std::vector<T>& values) {

for (auto it = values.begin(); it != values.end(); ++it) {

std::cout << *it << ' ';

}

std::cout << '\n';

}

template<typename T>

T maxValue(const T& a, const T& b) {

return (a < b) ? b : a;

}

// Функционалдық объект — предикат

struct IsPositive {

bool operator()(int value) const {

return value > 0;

}

};

int main() {
std::vector<int> values{5, -2, 8, 5, 0, 3, -1};
std::cout << "Bastapqy derekter: ";

printContainer(values);

std::sort(values.begin(), values.end());
std::cout << "Suryptalgan derekter: ";

printContainer(values);

long long sum =

std::accumulate(values.begin(), values.end(), 0LL);

auto positiveCount =

std::count_if(values.begin(), values.end(), IsPositive{});
std::cout << "Qosyndy: " << sum << '\n';
std::cout << "On elementter sany: " << positiveCount << '\n';

int target = 8;

auto found = std::find(values.begin(), values.end(), target);

if (found != values.end()) {

std::cout << "Izdelgen element tabyldy: " << *found << '\n';

}

else {

std::cout << "Element tabylmady.\n";

}

std::set<int> uniqueValues(values.begin(), values.end());
std::cout << "Biregei elementter: ";

for (int value : uniqueValues) {

std::cout << value << ' ';

}

std::cout << '\n';
std::map<std::string, int> scores{

{"Ali", 85},

{"Dana", 92},

{"Miras", 78}

};

std::cout << "Student bagalary:\n";

for (const auto& entry : scores) {

std::cout << entry.first << ": " << entry.second << '\n';

}

std::cout << "int maksimumy: "

<< maxValue(10, 25) << '\n';

std::cout << "double maksimumy: "

<< maxValue(4.5, 3.2) << '\n';

return 0;

}

Жеке тапсырманың нұсқалары

Әр нұсқада контейнер, итератор, кемінде екі стандартты алгоритм және бір үлгілік функция қолданыңыз.

Қосымша тапсырмалар:

Сұрыптауды кему ретімен орындаңыз.

Өз предикатыңызды функционалдық объект түрінде жазыңыз.

Бос контейнермен жұмыс істеу жағдайын тексеріңіз. Орташа мән есептеу немесе табылған элементті оқу алдында қажетті шарттарды тексеріңіз.
